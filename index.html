Product overview

What is LogLens AI

A local, open-source alternative to Datadog, Splunk and Sentry. Your logs never leave your machine.

  • ✓Surfaces the few lines that matter out of millions
  • ✓Every anomaly comes with a score and a reason
  • ✓Runs offline, gates CI, costs nothing per GB
Features

Everything you need to go from noise to cause.

Built for developers and SRE teams who want answers, not another dashboard bill.

Semantic / neural detection

MiniLM embeddings group log lines by meaning, not by string match.

Explainable results

Each anomaly carries a 0-1 score and human-readable reasons.

Incident grouping

Repeats collapse into incident families, with an INCIDENT flag when a run is severe.

Three modes

fast TF-IDF, turbo multiprocess for huge files, deep neural.

Warm daemon, ~7× faster

A resident process keeps the ML stack loaded: about 2.4s down to 0.33s per run.

CI/CD gating

--format json + --fail-on gate builds, plus an official GitHub Action.

Real-time watch

Tail a live stream and see only the anomalies as they happen.

Offline HTML reports

Self-contained incident reports you can attach to a postmortem.

Train your own model

loglens train on your logs, then analyze with --model.

Optional AI root-cause

Bring your own LLM key for a plain-language "why it broke" summary.

Demo

See every command in action.

Command cheatsheet
Fast (default)
loglens analyze --source app.log
Turbo, for huge files
loglens analyze --source huge.log --turbo
Deep, neural
loglens analyze --source app.log --deep
Train on your logs
loglens train dataset.log -o model.pkl
loglens analyze --source app.log --model model.pkl
CI/CD gate
loglens analyze --source app.log --format json --fail-on error
Warm daemon
loglens daemon start
How it works

Seven steps, all on your machine.

  1. 01

    Parse

    Format auto-detected, lines streamed.

  2. 02

    Templates

    Messages mined into templates.

  3. 03

    Represent

    TF-IDF or neural vectors.

  4. 04

    Detect

    Every line scored 0 to 1.

  5. 05

    Group

    Repeats become incident families.

  6. 06

    Explain

    Reasons, plus optional AI root-cause.

  7. 07

    Deliver

    Terminal, JSON, HTML or CI gate.

Install

Up and running in 30 seconds.

Debian / Ubuntu
$ curl -1sLf 'https://dl.cloudsmith.io/public/loglensai/loglensai-363o/setup.deb.sh' | sudo -E bash
$ sudo apt install loglens
Fedora / RHEL
$ curl -1sLf 'https://dl.cloudsmith.io/public/loglensai/loglensai-363o/setup.rpm.sh' | sudo -E bash
$ sudo dnf install loglens
Homebrew
$ brew install loglensai/tap/loglens
winget
> winget install LoglensAI.LogLens
pipx (recommended) or pip with neural mode
$ pipx install loglensai
$ pip install "loglensai[deep]"
Multi-arch image (amd64 + arm64)
$ docker run --rm -v "$PWD:/data" loglensai/loglens analyze --source app.log

Native installs bundle neural mode and start a warm daemon automatically.
