Documentation

Local, explainable log anomaly detection — from your terminal or inside your Python app.

Installation

LogLens runs on Python 3.10+ (Linux, macOS, Windows).

# core
$ pip install loglensai

# with neural "deep" mode (transformers)
$ pip install "loglensai[deep]"

Quick start

# scan a file — worst incidents first, each explained
$ loglens analyze --source app.log

# faster multiprocess scan for huge files
$ loglens analyze --source app.log --turbo

# save a shareable, offline HTML report
$ loglens analyze --source app.log --html report.html

analyze

The core command. Reads a file, stdin, a URL, or the output of a command.

FlagWhat it does
--sourceFile path, URL, or - for stdin (required)
--turboFast multiprocess scan for large files
--deepNeural embeddings (accurate, slower)
--rcaAI root-cause analysis (bring your own LLM key)
--htmlWrite a standalone HTML report
--modelUse a model trained with loglens train

watch

Stream anomalies from a live command — Docker, Kubernetes, journald, anything.

$ loglens watch "docker logs -f my-api" --rca
$ loglens watch "kubectl logs -f deploy/api"
$ loglens watch "journalctl -f"

CRITICAL/FATAL lines surface instantly; noise is filtered. Ctrl-C prints an incident summary.

ask

Ask your logs a question in plain English (needs an LLM key).

$ loglens ask "why did checkout start timing out?" --source app.log

benchmark & train

Measure accuracy on labeled logs, or train a supervised model.

# reproducible accuracy on labeled data
$ loglens benchmark BGL.log --format bgl --supervised

# train a supervised model, then use it
$ loglens train labeled.log --out model.pkl
$ loglens analyze --source app.log --model model.pkl

Python SDK

Everything the CLI does, programmatically.

from loglens import analyze

result = analyze("app.log")              # a file
result = analyze(lines=my_lines)          # lines you already have
result = analyze(cmd="docker logs api")   # a command's output

for a in result.anomalies:
    print(a.level, a.score, a.message, a.reasons)

print(result.summary())

In async apps, use await analyze_async(...). For custom streams, feed lines to LiveDetector.

Logging handler

Make any Python app alarm on itself — one line.

import logging
from loglens import LogLensHandler

logging.getLogger().addHandler(
    LogLensHandler(on_anomaly=lambda a: notify(a))
)

Docker

Multi-arch images (amd64 + arm64) — no Python needed on the host.

# scan a file (mount its folder at /data)
$ docker run --rm -v "$PWD:/data" loglensai/loglens analyze --source app.log

# watch a running container
$ docker run --rm -v /var/run/docker.sock:/var/run/docker.sock:ro \
    loglensai/loglens watch "docker logs -f my-api" --rca
